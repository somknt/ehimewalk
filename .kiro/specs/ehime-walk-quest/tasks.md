## ブランチ統合の記録（integrate：main ＋ shiomi）

- 土台は main（sugiyama1）。同じ機能はすべて sugiyama1 の実装を残した（ガチャ、着せ替え、ホーム、コイン表示、デモ操作、モックサーバー）
- shiomi から取り込んだもの：キャラクター作成、ログインボーナス、健康ミッション、AI 散策クエストの条件入力、スポット詳細と GPS チェックイン、愛媛冒険図鑑、AI 観光ガイド（モック）、ランキングの中身と応援、マイページの中身、domain の checkin / mission / titles / questPlanner
- 保存データはバージョン 3 にした。バージョン 1・2（sugiyama1 の形と shiomi の試作版の形）は読み込み時に移行する
- 確認：`npm test` 77 件成功（main のテスト 3 ファイル＋取り込んだ機能のテスト）、lint・ビルド成功、ブラウザで「キャラクター作成 → ログインボーナス → ガチャ → 着せ替え → AI クエスト・チェックイン・図鑑 → ランキング → マイページ → 再読み込み → データ削除」を確認
